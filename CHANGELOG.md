# Changelog

Relevant changes per version. New entries are added at the top.

## 1.1 – 2026-11-04

- Product options can now be changed individually.
- Calculated options are now displayed more clearly.
- When loading, the saved configuration in the project is preferred (including custom options).
- Temporarily restored products are automatically cleaned up when closing.

## 1.0 – 2026-11-01

First documented functional state (version shown in Info dialog).

- Select, edit, create new, copy, and delete products.
- Calculate prices live from base price + options × quantities.
- Display results and copy to clipboard.
- Save/load projects as `.pcproj` including embedded product configuration.
- Configure currency via `settings.json`.
